## Repository Description

Digital scanline toolkit for extracting, grouping, reconstructing, and visualizing structural features from 3D rock-wall meshes and point clouds.

## Feature Summary

- Adaptive arc-based scanline layout.
- Mesh-section extraction from triangular surface models.
- Fragmented segment ordering with graph/path logic.
- Overhanging feature recognition using local geometric vectors.
- Multi-profile grouping and centroid extraction.
- Mesh/voxel-based structural unit reconstruction and volume estimation.
- PyVista/Open3D/Matplotlib visualization helpers.

## Publication Boundary

This release contains code, documentation, example configuration, and sanitized visualization images. It does not contain raw survey data, private 3D models, institution metadata, or case-site identifiers.
